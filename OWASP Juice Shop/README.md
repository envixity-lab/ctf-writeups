# OWASP Juice Shop Write-Ups

## Disclaimer

This repository contains write-ups and security assessments completed against OWASP Juice Shop, an intentionally vulnerable web application designed for security training, Capture The Flag (CTF) challenges, and ethical hacking education.

The techniques discussed in this repository are documented for educational purposes only. This is **not** a guide for attacking real-world systems, and the information provided should only be used in environments where you have explicit authorization to perform security testing.

Many of the vulnerabilities documented here are based on real-world attack techniques used by security professionals during penetration tests and security assessments. Never attempt to reproduce these techniques against systems you do not own or do not have permission to test.

---

## About OWASP Juice Shop

OWASP Juice Shop is a deliberately insecure online store created by the OWASP Foundation to teach web application security. It contains challenges ranging from beginner to advanced difficulty and covers a wide variety of real-world vulnerabilities.

The application includes hundreds of challenges across areas such as:

* Authentication
* Authorization
* Sensitive Data Exposure
* Injection Attacks
* Business Logic Flaws
* Security Misconfigurations
* Client-Side Vulnerabilities
* API Security

Because of the large number of available challenges, this repository does **not** contain every challenge I have completed, nor do I plan to document them all.

At the time of writing, I have completed more than 40 Juice Shop challenges. This repository contains a selection of approximately 10 of my favorite findings and some of my earliest attempts at web application security testing.
